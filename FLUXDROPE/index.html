Cryptographic Architecture

Zero Server Retention: Files are sliced into binary memory buffers and streamed over direct WebRTC SCTP data channels.
Hardware-Accelerated AES-256-GCM: Optional passwords derive 256-bit symmetric keys via PBKDF2 (100,000 SHA-256 iterations) with authenticated tags for each slice.
Double E2EE: In addition to the native DTLS transport encryption in WebRTC, payloads are encrypted application-side before transmission.

About FLUXDROPE

FLUXDROPE

Created By Shiv Yogi

FLUXDROPE was built to solve privacy vulnerabilities in contemporary file sharing. Standard file transfer services upload your data to intermediate servers and cloud storage buckets. FLUXDROPE completely eliminates intermediate storage through direct peer-to-peer browser links.

Real-time WebRTC DataChannel transfer with no file size limitations
Optional client-side AES-GCM 256-bit encryption with PBKDF2
Zero trackers, zero analytics, zero logs
